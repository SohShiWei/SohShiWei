## 🚀 Featured Projects

### [VPIC — Venepuncture & IV Cannulation AI Training System](https://github.com/SohShiWei/VPIC_ObjectDetection)

> Real-time syringe & needle object detection pipeline for AR/VR clinical skills training on Meta Quest 3

**Stack:** Python · YOLOv8n · ONNX · Unity Sentis · Meta XR SDK · OpenCV · PyTorch

| Metric | Score |
|--------|-------|
| mAP@0.5 | **99.5%** |
| Precision | 98.8% |
| Recall | **100%** |
| Training time (GPU) | ~4 min (RTX 4050) |

**Architecture:**
```
Quest 3 Passthrough → Frame Preprocessing → YOLOv8n (ONNX / Unity Sentis) → AR Bounding Box Overlay → Real-time Trainee Feedback
```

Part of a broader system with stereo depth estimation, a React analytics dashboard, and haptic feedback integration.
